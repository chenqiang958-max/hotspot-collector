热点收集器 · 使用说明
================================================

一个帮你收集微博、B站、知乎、小红书以及任何网页热点内容的工具。
抓来的内容自动分类，方便你找选题、找需求、找热点。


【一、第一次使用（只做一次）】

1. 双击"首次安装.bat"，等它自动装完（很快）。

2. 双击"自检.bat"，看到"7/7 通过"就说明一切就绪。

3. 浏览器要求：软件需要用 Chrome 或 Edge 浏览器
   （Edge 是微软的，Win10/11 系统自带，蓝绿色漩涡图标）。
   这两个都行，软件会自动找。不支持 Firefox、IE。


【二、启动软件】

双击"启动.bat"。会发生两件事：
1. 弹出一个黑色命令行窗口（这个别关，关了软件就停了）
2. 自动弹出一个浏览器窗口，里面就是软件的操作界面

注意：这个浏览器是软件专用的独立浏览器，跟你平时用的浏览器分开。
所有操作、登录，都在这个窗口里进行。


【三、登录各平台（第一次要登一遍）】

微博、B站、知乎、小红书都需要登录后才能抓到完整内容。

操作步骤（以微博为例）：
1. 在软件界面，找到"微博"卡片，点"登录"
2. 浏览器会打开微博网页（在同一个浏览器里，新标签）
3. 在这个标签里扫码登录微博（跟平时登录一样）
4. 登录成功后，回到软件操作页面的标签，点微博的"完成"
5. 看到"登录成功"，微博卡片状态变绿色"有效"

四个平台都这样登一遍。这个浏览器会记住登录，以后不用每次重登。

提示：如果点"完成"提示读不到浏览器，是因为那个浏览器窗口被关了，
重新点"登录"打开就行。


【四、抓取内容】

方式1：平台一键抓（微博/B站/知乎）
在平台卡片上点"抓取"，软件自动抓该平台的热榜：
- 微博：热搜总榜
- B站：综合热门、每周必看、入站必刷、排行榜、音乐榜（五个榜）
- 知乎：热榜 + 大家都在搜
抓取时下方会显示进度条，完成后自动刷新显示数据。

方式2：地址栏抓任意网页（小红书 + 其他所有网站）
这是最强大的功能——浏览器能打开的任何页面都能抓。
1. 在"抓取网页"区域的地址栏，粘贴任意网址
   （小红书某频道、微博文娱榜、抖音、任何网站…）
2. 如果是微博/B站/知乎/小红书，软件自动认得、自动归类，备注可不填
3. 如果是其他网站（软件不认识的），在"备注"框填个分类名
   （比如"抖音热榜"），软件按你的备注归类
4. 点"抓这个网址"，软件自动打开、等加载、抓取
5. 看进度条，完成后自动刷新

小红书就用这个方式抓（它有签名保护，只能这样）：
在浏览器打开小红书某频道 → 复制网址 → 粘到地址栏 → 抓。

方式3：抓浏览器当前打开的页面
如果你已经在浏览器里打开了想抓的页面，直接点
"抓取浏览器当前已打开的页面"，软件读取所有已打开页面的内容。


【五、常用网址（存起来一键全抓）】

如果有些网址你经常要抓（比如微博各分类、常看的话题）：
1. 在地址栏输入网址和备注
2. 点"存入常用"
3. 存好的网址显示在下方列表
4. 以后点"一键全抓"，软件挨个打开、抓取所有常用网址

举例，你可以存：
- 网址=微博文娱榜地址，备注=微博-文娱
- 网址=小红书职场频道地址，备注=（留空，自动认小红书）
- 网址=知乎搜"验光师"的地址，备注=（留空，自动认知乎）


【六、查看和筛选数据】

- 大列表：所有内容一列，每条标了平台颜色和来源榜单
- 按标签分板块：按 重点关注/需求类/话题类/教育考证/效率工具 分区
- 筛选：按平台、按榜单、按标签、按时间、关键词搜索
- 趋势箭头：连续抓几天后，显示某话题比上次更热还是降温
- 监控词：命中"验光师、初级会计、PDF转Word、题库"的内容自动标红
- 导出Excel：点"导出Excel"，把当前筛选结果导成表格


【七、定时自动抓】

想让它自动定时抓（不用手动点）：
双击"定时抓取.bat"，每60分钟自动抓一次微博/B站/知乎。
（小红书和地址栏网址不在定时范围，需要手动抓）


【八、出问题怎么办】

软件文件夹里有个"软件日志.txt"，记录了所有操作和错误
（时间、平台、具体错误）。遇到任何问题，把这个文件发出来，
就能查到原因。

常见问题：
- 点完成读不到浏览器 → 那个登录浏览器窗口被关了，重新点登录
- 小红书抓取失败(406) → 别用小红书卡片的"抓取"，改用地址栏抓
- 抓到的内容不对/是旧的 → 确认抓的是热榜页面，不是推荐页


【九、每天怎么用（推荐流程）】

1. 双击"启动.bat"
2. 如果状态没掉线，直接点微博/B站/知乎的"抓取"
3. 小红书：浏览器打开想看的频道，用地址栏抓（或存进常用一键全抓）
4. 看数据、筛选、导出
5. 用完关掉命令行窗口即可

登录状态能保持挺久，掉了（状态变红）再重新登一次就行。
